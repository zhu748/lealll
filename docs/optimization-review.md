## 保留的功能与分类

原 `/admin` 看板、多账号加密存储、账号编辑/禁用/备份恢复、自动故障转移、每账号代理、HTTP/SOCKS 代理池、统计、日志、调试转储、验证码 worker、MCP 反代、闲时通道、领取和额度重置继续保留。后台公共入口仍为 32 行，原公开导出和路由契约测试继续执行。

新增公共逻辑集中到 `auth/selection.ts` 与 `utils/serial.ts`、`abort.ts`、`fetch-json.ts`、`stream.ts`；各功能模块调用这些辅助函数，避免复制凭据选择、串行状态更新、取消与流量限制逻辑。

- Android CJS bundle 编译后用 Node 实际启动控制入口和代理，再验证完整 shutdown JSON 回复与进程退出码 0。
- CLI 源码与 Android bundle 的版本均为 `4.7.8-fork.1`；启动脚本命令核对、`start.sh` 语法和 `start.bat` ASCII/CRLF 校验通过。

## 发布与边界

按 `release.md` 推送版本标签，由 GitHub Actions 编译、打包和发布 5 个桌面平台 zip、Android APK 与 `linux/amd64`/`linux/arm64` GHCR 镜像。构建状态与最终附件以本版本 Release 页面为准。

ResponseStore 仍是进程内缓存，重启清空；超大响应继续正常返回，但不会占用超预算历史缓存，因此无法用于后续 `previous_response_id`。字节预算为序列化记录及固定开销的估算，不等于完整 JavaScript 堆大小。取消可中断网络和等待，不能回滚上游已经处理的模型请求。
