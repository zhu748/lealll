# 系统提示词替换与删除

启动代理后打开 `/admin`，进入「全局设置 → 提示词」。规则编辑与最近请求对照位于同一页签，桌面使用双栏对照，窄屏使用上下排列。

## 三条默认规则

| 规则 | 默认行为 | 匹配方式 |
| --- | --- | --- |
| Claude Code 身份 | 将身份声明改为 `You are ZCode model working in Claude Code.`，兼容包含 Claude Agent SDK 后缀的声明 | 整行匹配 |
| Claude 模型与 Fast 模式营销 | 删除包含 `The most recent Claude models are` 或 `Fast mode for Claude Code uses Claude Opus` 的整行，两句合并在同一条规则中 | 整行匹配，每行一个关键词 |
| 指定 IMPORTANT 段落 | 删除指定的 `IMPORTANT: Assist with authorized security testing…` 完整段落 | 精确文本匹配 |

三条规则的名称、匹配文本、操作和替换文本均可编辑，也可逐条关闭或删除。点击「添加规则」可增加自定义规则；上移/下移改变执行顺序。「恢复默认规则」先更新草稿，再点击「保存提示词规则」生效。

## 匹配与执行

- **精确文本**：大小写敏感，按原文匹配，可跨多行；所有命中位置均替换。替换文本中的 `$&`、反斜线与 HTML 按普通文本处理。
- **整行匹配**：每行填写一个关键词，任一关键词出现在系统提示词的某一行中，就替换或删除该整行。匹配关键词去除首尾空格，其他文本保持原样。
- **删除**：替换文本为空；删除后为空的系统文本块会移除。
- **顺序**：按规则列表依次处理，后面的规则能够匹配前面规则产生的文本；每条规则对一个文本块执行一次。
- **范围**：只改写系统提示词，保留用户消息、工具定义和工具结果。对 `/v1/messages`、`/v1/chat/completions`、`/v1/responses` 生效，两种套餐均支持。
- **时机**：客户端协议转换和 Start 套餐系统块注入完成后改写。配置保存仅影响之后收到的请求；重试切换套餐时从未修改的请求重建，避免重复注入与编辑。

## 命中与对照

面板显示最近请求的每条规则是否启用、是否命中、命中次数、修改次数以及跳过原因。命中但替换文本相同，或后续规则恢复原文时，会显示最终内容未改变。刷新对照不会覆盖未保存的规则草稿。

原始内容在请求收到时捕获，上游内容在实际发送时记录，二者属于同一个请求。较早请求的重试不会覆盖新请求的对照。收到请求但尚未发送时显示等待状态；重试时更新发送次数和最后发出时间。

对照只在服务进程内存中保留最近一份，使用已有管理接口认证，退出面板会清空页面显示，重启服务后清空记录。每侧最多显示 128 Ki 字符，超出部分明确标记截断，实际上游请求不因此截断。「清空记录」仅删除对照，保留规则配置。

最多 64 条规则，每条匹配/替换文本最多 16384 字符。一次请求的替换内容最多额外增长 1 Mi 字符（1,048,576 字符）；超过预算的匹配会跳过，并在命中状态中显示原因。

## 配置文件

```yaml
promptRewrite:
  enabled: true
  rules:
    - id: custom-rule
      name: 自定义系统文本
      enabled: true
      action: replace
      matchMode: text
      match: "原文本"
      replacement: "新文本"
```

省略 `promptRewrite` 或其中的 `rules` 会加载三条默认规则；`rules: []` 表示没有规则，重启后仍保留空列表。`enabled: false` 暂停改写，同时仍记录实际系统提示词对照。

配置经 `PUT /admin/api/config` 保存与热更新；`GET /admin/api/prompt-rewrite` 返回最近对照及默认规则，`DELETE /admin/api/prompt-rewrite` 清空对照。记录不会写入配置文件。
